# Skill roadmap

No executable Skills exist in this foundation.

First implement `comic-production-planner` against the draft schemas after exercising a real issue: format selection, page budget, panel defaults/overrides, advertising and Story handoff. Then add rendering, assembly/lettering and preflight workflows based on observed needs. Keep narrative storyboard direction in the Story framework.

## Documented preparation is not implementation

Optional [lettering/print guidance](../guides/lettering-and-print-pilot.md), [blank pilot forms](../templates/production-pilot/README.md) and [import expectations](../guides/import-expectations.md) now support a real-project trial. They are not installed Skills, an InDesign script or a tested PDF pipeline. After example intake and a successful manual pilot, implement the smallest useful import and verify repeated updates, conflicts, overflow and exported output before expanding automation.
