# Print review checklist

Use with an [output review](output-review.md) for the exact revision. This blank checklist is not evidence of completed review.

## Editorial and visual

- [ ] Text matches the accepted Story/adaptation snapshot; corrections synchronized.
- [ ] Speakers, balloon tails, captions and reading order are clear.
- [ ] Overflow, missing glyphs, unwanted breaks and clipping checked.
- [ ] Readability assessed at actual print size.
- [ ] Facing pages, ad interruptions and page-turn intent checked.
- [ ] Artwork matches the relevant accepted identity and protected details remain visible.
- [ ] Covers, credits, imprint, editorial and ads complete; no unresolved placeholders.
- [ ] URLs/QR codes verified in output and at print size, where used.

## Technical and export

- [ ] Current printer requirements resolved and recorded in the print specification.
- [ ] Trim, bleed, safe area, page count/order and cover handling checked.
- [ ] Links current, fonts available and permitted embedding verified in output.
- [ ] Effective image resolution at final placement meets the selected specification.
- [ ] Colors, profile/output intent where required, spot colors, black and overprint checked.
- [ ] Native-document preflight has no unresolved relevant errors.
- [ ] PDF settings, marks and page/spread delivery follow the current specification.
- [ ] Exported PDF reopened; every page inspected, with page count and page boxes checked.

## Release and archive

- [ ] Findings resolved or explicitly dispositioned by the authorized project decision.
- [ ] Exact PDF revision/checksum and release evidence recorded.
- [ ] Source document, linked assets, permitted fonts and export settings inventoried.
- [ ] Delivery package matches the requested scope.

Do not send, publish or order printing merely because this form exists. Carry out delivery only within the user's actual authorization.
